# V2 handoff — validation-only feature optimization

V1 configuration, original test result and artifacts are preserved. A fresh V1 search reproduced every saved validation candidate to 1e-12, including E1/E2/E3 best macro F1 0.0914/0.0584/0.0230. V2 tested 56 bounded configurations across E4 HOG + RGB/HSV histogram, E5 pixels + PCA, and E6 HOG + histogram + PCA; all learned PCA fits use train only and validation selects every parameter and the overall winner. V2 never predicts the test set. See `configs/experiments_v2.yaml` and README for full settings, dimensions, accuracy and timings.

Validation best macro F1: E4 0.2003, E5 0.1334, E6 0.2127. E6 (HOG 8, HSV histogram, 128 components, k=3, cosine, distance weights) is selected; +0.1212 absolute over the V1 E1 validation score. Best E4/E6 HSV variants exceed corresponding RGB variants, but the separate searches and small validation set do not establish generalization or isolate a causal contribution for each choice. E6 and E4 differ by about 0.0124 macro F1; do not assume this difference generalizes. Validation has only ten examples per class and has been reused across 56 candidates, so selection optimism is a serious risk. The saved V1 test F1 0.0807 is a different model and should not be compared as V2 test evidence.

Outputs: `results/v2/metrics/comparison.json`, `validation_search.json`, `baseline_reproduction.json`, per-experiment validation predictions and confusion matrices; `results/v2/figures/` comparison, confusion and error panels; `results/v2/models/` selected candidate per V2 family. Cache and outputs are ignored by Git, so archive externally if needed. `python -m scripts.check_v2_artifacts` verifies local model predictions, metrics, confusion matrices and provenance against saved artifacts. Pickles are unsafe from untrusted sources. V1 notebook verification writes into an isolated V2 subfolder. Original V1 notebooks have stable cell IDs.

Runtime comparison is split into feature extraction, PCA fit/train transform, validation transform and K-NN fit/predict; PCA fits are shared among candidates. V1 feature extraction timing was not captured and must not be inferred. This environment measured V2 feature extraction of all variants in 7.82 seconds; timings are machine dependent. PCA uses the first 64 or 128 components from the same train-only randomized 128-component fit, rather than separately fitting 64 components.

V3 priorities: (1) inspect validation mistakes and report only visually supported observations; (2) pre-register future validation experiments and avoid using the existing test for iterative tuning; (3) assess stability with training-only cross-validation or repeated seeds while preserving the official split, then define a final evaluation protocol; (4) consider aspect-preserving preprocessing and further interpretable color/texture features only if justified by observed errors. Keep the low train sample count, class imbalance in test, environment portability and potential validation overfitting visible in any report.
