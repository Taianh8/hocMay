# V1 handoff — verified baseline

Python 3.11.15 on macOS arm64; installed versions are recorded in `requirements-lock.txt`. Imports and `pip check` succeeded; pytest passed 6 tests. The nine notebooks ran in sequence; executed copies and timings are in `results/notebooks/`. Jupyter needs loopback access; the sandbox blocked it, so notebook execution required permission to run outside the sandbox. The notebook format currently emits a missing-cell-ID warning; it did not prevent execution but should be addressed before future nbformat versions make it an error.

The images archive was downloaded from the mirror linked in README and matched torchvision's published MD5; the two Oxford metadata files also matched. The loader decoded and verified all 8,189 images, with 102 classes and disjoint, exhaustive official splits: 1,020 train, 1,020 validation, 6,149 test. Each class has 10 train and 10 validation images; test class counts range from 20 to 238. All image modes were RGB. See `results/metrics/dataset_metadata.csv` for dimensions and IDs.

Validation best configurations (accuracy / macro F1): E1 pixels + K-NN k=1: 0.1088 / 0.0914; E2 HOG + K-NN k=1: 0.0608 / 0.0584; E3 HOG + decision tree unlimited depth, min leaf 1: 0.0245 / 0.0230. E1 was selected using validation only. E1 test: accuracy 0.1057, macro precision 0.1275, macro recall 0.1052, macro F1 0.0807, weighted precision 0.1621, weighted recall 0.1057, weighted F1 0.0853. The remaining configurations were not tested. HOG did not beat pixels here. These scores are weak; they are evidence of a baseline, not suitability for deployment.

`results/metrics/validation_search.json` records every candidate and timing; `selection.json`, `test_metrics.json`, `test_predictions.csv`, `confusion_matrix.npy` and `confused_pairs.csv` record the decision and outputs. `results/figures/` has EDA, preprocessing, error and confusion plots. `results/models/selected_model.pkl` is trusted-local-only. Data, feature cache, model and generated outputs are Git-ignored. The feature cache contains 8,189 × 12,288 pixel and 8,189 × 1,764 HOG float32 values, about 439 MiB uncompressed; the compressed cache is about 172 MiB. The pipeline rerun reported a peak resident set of 1,226,932,224 bytes (about 1.14 GiB); the notebook runner reported about 1.13 GiB. These are machine-specific measurements, not a portable memory budget. The pipeline log is in `results/metrics/pipeline_execution.log`.

Decisions: official split unchanged; validation macro F1 then accuracy, with stable configuration order for ties; final estimator is fitted on train only; no learned transforms. IDs in outputs are official 1–102. Resize to square distorts aspect ratios, HOG discards color, class names are not provided, and the test set is imbalanced. Repeated analysis or tuning on test would bias later claims. Pinned versions are specific to this verified platform, without hash-locked wheels. Archive MD5 verifies agreement with torchvision's published value but is not a signature.
